# 百变机甲之戏剧变脸

这是一个以 Galbot G1 人形机器人为载体的智能文化交互项目，将川剧变脸、京剧身段、舞台音频与机器人动作控制结合，形成可编排、可展示的戏剧表演系统。

## 目录结构

- `galbot-sdk-web-console/`：机器人 Web 控制台、三维模型、音频资源和动作轨迹。
- `galbot-sdk-web-console/trajectories/`：京剧及组合动作轨迹，包含 `jingju_*.json`。
- `galbot_animation/`：视觉跟踪、人脸识别和头部动作相关代码及模型。
- `ring_bell_demo/`：摇铃演示代码。
- `tts/`：语音合成调用脚本。
- `galbot_delivery/`：交付说明和原始交付包校验记录。

## 说明

本仓库代码由 2026 年 11 月 8 日的机器人项目备份整理而来。虚拟环境、缓存、录制文件、运行输出、人脸数据以及包含设备凭据的运维诊断脚本未提交到公开仓库。

机器人运动相关功能必须在现场安全条件满足、设备状态确认且操作人员明确授权后运行。
